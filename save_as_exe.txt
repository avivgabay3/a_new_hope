# Build ScanOT2 into a standalone EXE

# 1) Install PyInstaller (and wheel dependencies) in your environment
#    pip install pyinstaller
#    (If you also need Pillow for icons, install with: pip install pillow)

# 2) From the repository root, run the spec file so bundled assets (config, cursor, theme, icons)
#    are included next to the executable. The spec resolves its path via sys.argv[0], so make sure
#    you invoke it from this directory. UPX is disabled in the spec to avoid Pillow extraction errors
#    like "Failed to extract PIL_imaging...". If you built previously, delete old dist/build folders
#    first (Windows):
#       rmdir /s /q dist build
#    Then build:
#       py -3.11 -m PyInstaller mainApp.spec
#    (Use "python -m PyInstaller mainApp.spec" if python is already on PATH.)

# 3) The portable build will be placed in ./dist/mainApp/ with mainApp.exe and the
#    bundled resource files. Copy that folder to another PC and run mainApp.exe directly.

# Notes
# - The spec hides the console window (console=False). Set console=True inside mainApp.spec
#   if you prefer to see stdout/stderr while running the EXE.
# - The spec now bundles the OpenCV FFmpeg DLLs automatically. If you see "VideoWriter failed to open" in
#   mainApp.log, rebuild with this spec and run the EXE from a folder you can write to.
# - If you want a custom taskbar icon, drop an app_icon.ico file in the repo root before building.
# - Runtime errors are logged to mainApp.log next to the EXE. Run the EXE once, then open that file if
#   the UI does not appear.
